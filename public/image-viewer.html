📋 複製配置指令

請複製下面的指令，在終端中執行以更新配置：
💡 完整流程說明：
步驟 1 - 保存配置：
1. 點擊「複製指令」或「保存配置」按鈕，命令會自動複製到剪貼板
2. 在終端中貼上並執行該命令（請確保完整複製整個命令）
3. 系統會自動更新 image-assignments.json 文件

步驟 2 - 應用到網頁：
4. 點擊「應用到網頁」按鈕，命令會自動複製到剪貼板
5. 在終端中貼上並執行該命令
6. 系統會將配置應用到實際的代碼文件中（圖片會插入到對應的頁面）
7. 執行完成後，刷新瀏覽器頁面查看效果

⚠️ 如果遇到 "command not found" 錯誤：
• 可能是命令被截斷了，請確保完整複製整個命令（從 "echo" 開始到 "update-image-config" 結束）
• 或者使用替代方案：複製下方的 JSON 配置，保存到 image-assignments.json 文件，然後執行 npm run analyze-images

⚠️ 重要：如果不執行命令，配置變更只會存在於記憶體中，不會保存到文件或應用到網頁。
